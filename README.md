# Mom Deen Journal

A gentle Islamic journal and planner for everyday ibadah, reflection and growth.

## Repository files
- `README.md` — project notes
- `icon-192.png` — app icon (192 × 192)
- `icon-512.png` — app icon (512 × 512)
- `index.html` — main planner application
- `manifest.json` — Progressive Web App settings
- `service-worker.js` — app-shell caching for repeat visits and offline fallback

## Netlify
Publish directory: repository root (`.`). Upload all six files to the root of the new site or connect this repository to Netlify.

## Important
This build preserves the planner's existing browser-local storage. Login, customer accounts and cross-device cloud sync are separate setup steps and are not enabled by these six files alone.
